Features

🧠 Agentic planner

Observe → simulate 200+ shots → score → act, with 3 skill levels.

📚 RAG coach

TF-IDF retrieval over a carrom knowledge base, LLM answers via serverless API.

👁 CNN-style map

Two Gaussian convolution layers over a 32×32 occupancy grid.

⚙ Serverless backend

/api/coach (rate-limited Groq proxy) and /api/health on Vercel.

🔒 Security

Strict CSP, no inline JS, server-side keys, input validation, hardened Docker.

📱 PWA

Installable, offline-capable shell, stats saved locally, sound effects.

Architecture

Browser (Canvas + physics + planner + RAG + conv map) → /api/coach (Vercel function, rate limit, validation) → Groq LLM

CI: GitHub Actions builds the Docker image · Runtime: nginx-unprivileged, read-only FS, caps dropped.
